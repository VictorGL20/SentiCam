# SentiCam

Prototipo inicial de firmware para SentiCam, bastón inteligente portátil de asistencia para personas con discapacidad visual.

## Hardware previsto
- XIAO ESP32-S3 Sense
- VL53L0X
- MPU6050
- 2 servomotores MG90S
- Cámara integrada
- WiFi
- Aplicación móvil para procesamiento y alertas

## Estado
Base inicial de desarrollo en Visual Studio Code + PlatformIO. Incluye máquina de estados, lectura de sensores, control básico de servos, WiFi y estado de error/recuperación. Las funciones no implementadas aún están marcadas como TODO.
